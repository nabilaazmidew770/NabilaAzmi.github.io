# Nabila Azmi — Interior Design Portfolio

A responsive, static portfolio website created to present Nabila Azmi’s interior design work across villas, residences, offices, hospitality spaces, wellness environments, and commercial concepts.

The website is built with plain HTML, CSS, and JavaScript. It does not require a framework, database, build tool, or backend server.

## Website pages

- Home — introduction, profile, capabilities, experience, and selected projects

- Projects — searchable and filterable project collection with interactive image galleries

- Contact — direct email, WhatsApp, Instagram, and location information
